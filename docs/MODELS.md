## Loading a model

```python
# git clone https://github.com/BrandeisPatrick/tino && cd tino && uv sync
from tino.api import Decider
d = Decider.load("BrandeisPatrick/tino-distil", revision="<revision from the table>")
d.decide({"state": "...", "questions": {"q": {"type": "noul", "instructions": "...?"}}})
```

Answers follow TypeSafe's `/v1/systemone` shapes (noul probability; choice with per-option probabilities and confidence; score with expected level and legend). Probabilities are divided by the model's fitted temperature `T` unless `calibrated=False` is passed.
